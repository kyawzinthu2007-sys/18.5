# TSO Edu Vocabulary 10,000 Upgrade

- Vocabulary library expanded to exactly **10,000 unique English words**.
- Original hand-curated CEFR cards are preserved.
- Expanded entries are frequency-ranked learner vocabulary with CEFR bands assigned by frequency rank.
- Existing search, Browse, flashcard sessions, XP, streaks, and spaced-repetition review continue to use the same API.
- The API's `totalWords` now reports 10,000 automatically.
- Optional synonym/antonym fields are hidden in the UI when unavailable.
