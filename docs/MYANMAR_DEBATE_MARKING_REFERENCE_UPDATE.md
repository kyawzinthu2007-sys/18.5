# Myanmar Debate marking update

## Scoring behavior
The debate analyzer uses the user's supplied Myanmar rubric as the authoritative scoring structure:
- Position starts: 2 marks
- Body criterion 1: 3 marks
- Body criterion 2: 3 marks
- Conclusion/position confirmation: 2 marks
- Total: 10 marks

The interface displays the result as `X out of 10` and does not display a CEFR/level for အဆိုအချေ.

## External reference used for score-band wording
Online essay marking references commonly group 10-point performance into bands such as 9–10, 7–8, 5–6, 3–4 and 0–2. The system uses those bands only as descriptive wording; it does **not** replace the user's 2+3+3+2 rubric.

Reference examples:
- SEA Guidelines essay mark scheme: 9–10 outstanding, 7–8 good, 5–6 competent, 3–4 weak.
- Other 10-mark language/writing rubrics also distinguish content, organization, language, grammar, punctuation and spelling.
