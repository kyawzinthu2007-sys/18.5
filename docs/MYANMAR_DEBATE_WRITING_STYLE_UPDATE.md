# Myanmar Debate Writing Style Update

The Myanmar အဆိုအချေ generator now follows the supplied school-essay exemplars as a writing-style blueprint rather than copying any one essay.

## Style rules applied to new topics

1. Four-paragraph structure:
   - Paragraph 1: introduction and topic framing.
   - Paragraph 2: clear personal position (2 marks).
   - Paragraph 3: body argument according to the selected debate pattern (3 marks).
   - Paragraph 4: body argument + confirmation of the position (3 + 2 marks where applicable).
2. Formal written Myanmar register is preferred over conversational forms.
3. Arguments are expanded with cause/effect reasoning, practical consequences, examples, and comparison.
4. The generator uses topic-neutral scaffolding so a new topic can be substituted without copying the supplied sample essays.
5. The conclusion restates the writer's position in a formal way.
6. Paragraphs are separated cleanly so the Analyze system can score the four-paragraph rubric.
