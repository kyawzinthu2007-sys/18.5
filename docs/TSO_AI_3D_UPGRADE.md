# TSO AI 3D Character Upgrade

The TSO AI robot model has been upgraded to match the smoother, premium 3D appearance of the supplied reference design.

## Changes
- Added smooth, area-weighted per-vertex normals to every character mesh to remove faceted/block-like lighting.
- Preserved the existing glTF animation clips: Idle, Blink, Talk, Wave, Happy, Smile, and Wink.
- Refined PBR material roughness/metallic response for the white shell, jacket, face glass, purple accents, and eye glow.
- Improved `<model-viewer>` presentation with softer shadows, higher-quality exposure, and a subtle premium drop shadow.
- Kept the existing TSO Myanmar-inspired cream jacket, purple longyi, gold patterning, sandals, TSO emblem, and expressive face.
