# TSO Edu Speed + Responsive UI v3

## Included
- Responsive UI for laptop, iPad/tablet, iPhone 15–17 Pro Max class screens, Samsung and other Android phones.
- Safe-area support and compact phone breakpoints down to 360px.
- Animated tool launcher with clearly separated Analyze Writing, Generate Essay and Natural Writing Coach actions.
- Smooth section navigation and touch ripple feedback.
- Natural Writing Coach launch card explicitly states it improves an existing draft and is not essay generation.
- Generate and Analyze remain separate workspaces.
- Reduced-motion accessibility support.

## Deployment
No database migration or new environment variable is required. The update is frontend-only on top of the previous speed upgrade.
